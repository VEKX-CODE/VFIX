# 🔴 VFIX - Hardware PC Repair & Diagnostics Suite (v1.0.0 Pre-Release)

> **VFIX (VEKX)** — автономный комплекс экспресс-диагностики и восстановления ПК через прямое кабельное подключение смартфона Android к рабочей или аварийной станции Windows / WinPE.

---

## ⚡ О проекте

Комплекс состоит из двух независимых компонентов:
1. **Мобильный ассистент (Android APK)**:
   - Анимированный неоново-красный фон в стиле **Matrix Rain** (`60 FPS SurfaceView`).
   - 100% автономный локальный ИИ-диагност `VfixLocalAiEngine` (работает без интернета, API-ключей и внешних серверов).
   - Чтение аппаратных логов ПК через прямой защищённый USB-канал.
   - Быстрые чипы управления ремонтом (SFC, DISM, CHKDSK, Очистка Temp, Перезагрузка в BIOS/UEFI).
   - Автоматическая очистка кэша и логов при отключении кабеля.

2. **Агент ПК (Windows x64 / WinPE)**:
   - Полноэкранный киберпанк-интерфейс (Tkinter / PIL) с фирменным логотипом VFIX.
   - Сбор S.M.A.R.T. физических накопителей, поиск дампов синих экранов (BSOD) и критических событий Windows Event Viewer.
   - Фоновый кабельный мост для мгновенной передачи отчётов в телефон и приёма команд восстановления.

## 🚀 Инструкция по использованию

### Вариант 1: Запуск на рабочей / полуживой Windows
1. Установите **`VFIX.apk`** на телефон.
2. Подключите телефон к ПК через обычный USB-кабель (включите «Отладку по USB»).
3. Запустите на ПК **`VFIX_Agent.exe`** (или через батник).
4. На экране ПК появится статусная панель с логотипом, а на телефон мгновенно прилетит заключение диагноста с вариантами ремонта.

### Вариант 2: Запуск на сломанном ПК через WinPE флешку
1. Распакуйте **`WINPE_VFIX_PORTABLE.zip`** на загрузочную флешку (Ventoy / WinPE).
2. Загрузитесь с флешки на сломанном ПК.
3. Подключите телефон шнуром и запустите **`START_VFIX_WINPE.bat`** (или `VFIX_Agent.exe`).
4. Нажимайте кнопки на телефоне для запуска проверки диска, восстановления системных файлов или очистки мусора.
